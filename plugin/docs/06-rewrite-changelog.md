# 06 · 重写变更说明

日期：2026-10-06。本文件记录本目录**完全重写**相对上一版的取舍：删掉了什么、为什么删，以及新文档集如何对应。阅读本文件集不需要先读上一版。

## 1. 重写原则

1. **独立项目口径**。本目录从用户需求与本机安装内核（Core `0.2.1-alpha.1`）直接出发行文，不承接任何其它实现的框架、命名或版本关系。
2. **冻结语义以代码为准**。三入口行为、数据模型、状态机、恢复规则、错误码与预算表全部逐条对照 [`domain/*.mjs`](../domain/) 核验；不一致处在[02 §12](<02-protocol-and-data-model.md>)显式列出并以代码为准。
3. **验收 ID 不变**。`F01–F20`、`S01–S14`、`L01–L12` 与阶段 0 的 `G1–G8 + S08` 全部保留，因为测试与报告按 ID 锚定；只重述判据文字。
4. **事实与验收导向**。区分“已验证 / 未验证 / 不支持”，不写没有证据的结论。

## 3. 判定为过时或与本项目无关的叙述（逐类）

1. **跨版本承接叙事**：“某草案被本版取代”“不兼容早期格式”“按名字自动识别旧授权”等。协议只有 `PROTOCOL_VERSION = 2` 一个事实，不存在需要解释的历史版本关系。
2. **会话事件接口的迁移史**：把某个同步快照接口的采用 / 弃用写成一串演进过程。现在只保留一条当前约束——**该接口在本机已被标记弃用且禁止新调用，因此本项目不使用；恢复失败一律 fail closed**。
3. **会话迁移 / 额度暂停的过程叙事**：goal 状态、中断与恢复、子代理停启顺序、路由额度封禁等执行过程细节。它们不是设计约束，已从文档集移除；只保留结论性的“不支持 / 未验证”。
4. **环境修复过程叙事**：某次配置改动、备份哈希、故障复现与重启验证记录。属于本机运维记录，不是 PTD 的设计依据。
5. **对具体外部 commit、旧目录与旧代码树的引用**：重写后不再出现；证据只指向 `plugin/` 内的报告与本机安装内核。
6. **模型路由调研**：与产品设计无关，且其事实核验本身不完整，已整体移出。
7. **过时的接口说明稿差异**：上一版引用的接口稿在若干签名上与实现不一致（同步返回、附加参数、返回字段名、模块扩展名等）。这些差异**没有**作为历史保留，而是整理成 [02 §12](<02-protocol-and-data-model.md>) 的一张“文档与实现的已知差异”表，直接给出以代码为准的处置。
8. **未受证据支撑的绝对表述**：如“prefix cache 100% 保留”“本地 CPU 已降为 O(活跃工具数)”。新版本改为明确写出**未验证 / 不成立**的边界。
